
# Pixel Fair Web Design Project
This is my first web development project taken place during WEB101 Codepath course utilizing HTML, CSS, and Javascript to build and style a website for a fictitious event. I created a website to invite people to a cultural fair celebrating and exploring pixel culture through art, technology, music, and activities such as workshops and design jams. The website includes a smooth, animated interface showing a display of events, an RSVP form, FAQ section, and a footer with inline newsletter subscription registration. It allows users to toggle dark mode and reduced motion. 

## Intended Users
The website intends anyone who come across it to sign up. It seeks to intrigue those who are particularly interested in pixel art, music, or game development and would want to attend a fun and exploratory event. It is inclusive to all, so youth, adolescents, adults, and families are all welcome to use the website. Currently, it is best accessible and friendly to desktop and ipad users, and although I have adjusted the scalability to be mobile friendly, I've noticed that some elements are still not displayed properly.
